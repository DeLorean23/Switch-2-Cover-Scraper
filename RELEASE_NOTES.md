Switch 2 Cover Scraper for Batocera.

**Download the ZIP below**, extract it to `/userdata` and start the scraper from **Ports**.

Fetches box art, screenshots, logos, fanart and game info for the system **"Switch 2"** (`/userdata/roms/switch2`) from TheGamesDB – the scraper built into Batocera does not know Switch 2.

Features:
- **Choose what you want:** tick box cover (front/back), screenshot, title screen, logo, fanart and game info – or **All**. Your choice is saved.
- **Controller or keyboard:** D-pad to move, A to tick / start, B to exit
- **Only missing** or **re-scrape all**
- Searches the Switch 2 platform of TheGamesDB, falls back to Switch 1
- European covers preferred
- Writes the Batocera game list (backup `gamelist.xml.bak`) and reloads it in EmulationStation
- No account and no own API key needed

Requires the system "Switch 2" (e.g. from the [All-In Installer & Update](https://github.com/DeLorean23/All-In)).
